# Профессиональный Торговый Робот для XM (AI)

Этот бот создан для автоматической торговли на платформе XM через MetaTrader 5. Он использует передовые технические индикаторы и искусственный интеллект для принятия решений.

## Основные Возможности
- **Технический Анализ**: Использует стратегии на основе EMA, RSI, MACD и Полос Боллинджера.
- **Самообучение**: Бот обучает модель машинного обучения (Random Forest) на исторических данных конкретного инструмента, чтобы предсказывать направление цены.
- **Интеграция с XM**: Работает напрямую через Python-библиотеку MetaTrader 5.
- **Профессиональные Стратегии**: Сочетает классический теханализ с современным AI.

## Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Убедитесь, что терминал MetaTrader 5 запущен и разрешен "Алгоритмический трейдинг".
3. Настройте подключение в `xm_bridge.py` или передайте логин/пароль при инициализации.
4. Запустите бота следующей командой:
   ```bash
   python3 trading_bot/run_bot.py
   ```

## Принцип работы
Бот сначала анализирует историю (например, последние 500 свечей), рассчитывает индикаторы, а затем обучает AI модель отличать прибыльные сигналы от ложных. Только когда технический сигнал совпадает с прогнозом AI, бот открывает сделку.

**Внимание**: Торговля на финансовых рынках несет риски. Используйте бота на демо-счете перед реальной торговлей.

## Устранение неполадок (Troubleshooting)

### 1. Ошибка "MetaTrader5 library not found"
Это означает, что библиотека не установлена.
**Решение**: `pip install MetaTrader5`.
*Важно*: Официальная библиотека работает только на Windows. Если вы на Linux (Ubuntu/Debian), вам нужно использовать Wine для запуска MT5 и специальный мост (например, через HTTP API), либо запускать бота в Windows-среде.

### 2. Ошибка "mt5.initialize() failed"
Бот не может найти запущенный терминал MetaTrader 5.
**Решение**:
- Запустите терминал XM MetaTrader 5.
- Перейдите в **Сервис -> Настройки -> Советники**.
- Поставьте галочку **"Разрешить алгоритмическую торговлю"**.

### 3. Ошибка авторизации (Failed to authorize)
Неверный логин, пароль или сервер.
**Решение**: Проверьте данные в `run_bot.py`. Логин должен быть числом (ID счета), сервер должен точно совпадать с тем, что указан в MT5 (например, `XMGlobal-Real 1`).

### 4. Нет данных (No data received)
Символ (например, `EURUSD`) может называться иначе на вашем типе счета (например, `EURUSD!` или `EURUSD.m`).
**Решение**: Проверьте название символа в Обзоре Рынка и исправьте его в `run_bot.py`.
